# 原始设想：以 Figma 项目结构约束原型视觉一致性

## 背景

当前 PRD Skill 在生成低保真与高保真原型时，可能因参考图、上下文和生成批次变化而出现视觉风格漂移。

## 用户设想

- 以 Figma 项目作为隔离边界。
- 每个项目先建立 `Design System`，包含 Design Token 和 Component。
- 建立 `Views`，保存更具体、可复用的页面样式。
- 每个业务流程新建一个低保真 Page，以占位内容描述流程和页面结构。
- 高保真阶段必须使用 `Design System` 中已有设计；新设计先在 `Design System` 定义，再投入使用。
- 页面先在 `Views` 中封装，再由业务流程页面复用，以呈现业务逻辑。

## 评估目标

判断该方案能否降低视觉漂移、Figma 对象层级是否合理，以及当前 Skill 需要增加哪些可执行约束。
