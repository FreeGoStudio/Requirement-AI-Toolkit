# Storybook 平台发布

确认当前是用户指定的 Storybook 技能分支、正确的平台服务主维护目录及目标 Project/Requirement。读取该平台方案、README、现有运行配置和权限；凭据不输出、不入库。读取同级 prd/references/storybook-workflow.md 的生成与交付约定。

开发预览使用需求分支固定源码构建，可在开发期间发布，不要求合并或人工批准。正式持续原型只使用已人工确认的固定候选完整包，在明确授权后经平台 GitLab 合并与发布链路执行；不得代替用户审批。正常入口使用 Plane，异常才进入管理工作台。

收集全部已注册 App 的 storybook-static、包内播放器/SDK、配置、需求运行资料和模拟数据；通过平台 Artifacts 校验与归档。构建输出必须包含 index、iframe、索引和动态资源。发布前后核对 build_id、来源 SHA 和完整摘要，不重建、不链接改写、不按可达 HTML 裁剪，不上传凭据或整个源码仓库。

接口、认证和命令以目标平台当前实现为准。源码有新提交不更换已冻结候选，current 切换不改变旧会话。失败保留旧成功入口，按原操作恢复，不用旧 HTML 发布器绕过。缺少平台连接或授权时明确未发布，可继续已授权的本地校验；不自行开放公网或新建替代发布通道。

报告实际入口、build_id、摘要、来源、验证和发布状态；技术验证不能标为人工验收。历史 HTML 项目不自动迁移，本技能不调用旧 Prd/Html 模式。
