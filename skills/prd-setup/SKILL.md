# PRD 环境准备

服务器已由管理员准备好、用户仅需配置发布账号时，只做本机 Configure、InstallRuntime 和 Check，跳过 Initialize。使用提供的发布账号，不索取 root，不申请 sudo，不修改 Nginx；连接或发布失败不自动转为服务器初始化。

用中文检查技能安装、输出目录写入能力和浏览器预览能力。读取 `references/setup.md`，复用已有环境；用户仅要求检查时不安装、不修改配置。

默认 HTML/CSS/JavaScript 交付可直接在浏览器打开，无需服务端或额外运行时。用户需要 Linux 发布时，读取已安装 `prototype-publish/references/remote-publishing.md`，调用同一技能的 `scripts/Invoke-PrototypePublish.ps1` 完成配置、运行时安装、连接检查和 Nginx 初始化，不复制另一套部署代码。不修改其他服务配置。

配置前说明 HTTP 访问地址、网站端口和专用目录；沿用用户已确认的选择。密码通过本机安全输入框/PowerShell `Read-Host -AsSecureString` 输入，不要求用户粘贴到聊天，不把明文放进命令行。首次 SSH 指纹必须由用户核对，不能自行将探测指纹视为可信。仅检查时使用 Check，不安装或初始化。配置完成意味着后续原型更新自动发布，无需逐次确认上传。

按用户授权安装或修复 prd 后，使用独立临时目录生成一个含中文、相对资源链接和按钮反馈的 HTML 验收页，实际打开并点击。区分文件写入通过、浏览器打开通过、交互验证通过；缺少浏览器自动化时明确待验收，不把命令启动成功当成页面通过。

失败时保存实际错误，区分技能缺失、文件路径、资源链接与浏览器能力问题；相同错误连续两次且无新证据时停止重复操作，报告下一步。

完成后给出实际技能路径与验证结果，并提供可复制练习，不自动启动新需求：

```text
$prd 带我制作一个 PC 网页登录界面的 HTML 原型与 HTML 需求文档。
产品 ID：LOGIN_DEMO。
包含账号、密码与登录按钮，演示必填项缺失、登录失败与成功反馈。
只用模拟数据，不接真实接口，不做注册、忘记密码或第三方登录。
我没有参考截图，请先带我澄清业务规则，按阶段确认。
```
