# PRD 环境准备

用中文帮助用户连通 prd、Figwright 和 Figma。直接完成已授权配置，登录、无法自动完成的插件导入等才交给用户；每次说明当前操作。仅要求检查时不安装或修改配置。

## 1. 检查环境

读取 [配置步骤](references/setup.md)。首次配置按 Figma Desktop → Node.js/npm → prd 与 Figwright MCP → Figwright 插件 → 连接验收推进，已有可用项直接复用。检查安装记录、可执行文件及 PATH，未运行不等于未安装。缺项时按配置步骤自动下载安装；不要求 Figma personal access token。

## 2. 配置技能与服务

- 检查 `$CODEX_HOME/skills`，未设置时用 `%USERPROFILE%\.codex\skills`；核对 prd 入口及引用资源，区分缺失、重复安装和当前聊天未加载。
- 发现 `mcp__figwright__ping`；已有可用服务直接复用。缺失时按配置步骤安装/配置，不重复追加配置表，不改其他服务。
- 仅新增配置尚未加载时提示重新加载工具或重启客户端；恢复后重新探测，不把配置存在当作连接成功。

## 3. 连接与验收

- 在 Figma Desktop 的 Drafts 创建 Design 草稿，或复用本次验收文件；按配置步骤导入并运行 Figwright 插件，保持插件运行。
- 先 `ping`，再 `list_files`。多个文件连接时，根据用户指定目标用 `use_file` 绑定；同名用 `sessionId`，目标不明才询问。
- 调用 `get_pages` 读取真实页面，默认不要求另发链接。空白 Untitled / Page 1 可验证连接。fileKey 无法取得时如实记录，不能把 sessionId 当作文件 ID。
- 用节点读取工具定位现有可导出 Frame，调用 `get_screenshot` 并查看图像。空白文件没有可导出节点时记录“连接及页面读取通过，截图待验收”，不能自动写入测试节点或虚报截图通过。
- 页面读取与实际截图均通过即完成默认只读验收，直接交接；只读通过不代表写入通过。
- 仅用户要求读写验收时，在已指定文件的独立“连接验收”页创建含“连接成功”的 Frame。先读取并复用本技能验收节点；身份不明的同名内容不覆盖。使用 Figwright 专用创建工具，写后重新读取并截图；失败后先检查状态，不重复创建。
- 业务原型的工具映射、文件身份和治理要求见 prd 的 `references/figwright.md`。

## 4. 按实际错误排障

区分工具未暴露、服务启动失败、插件未连接、目标文件不明、编辑模式/权限不足、版本不兼容和截图失败。检查对应配置、插件状态和原始错误；不要按 node/npx 名称批量结束进程。若需重启，仅处理已确认属于本任务的实例；影响其他任务时先说明影响并取得授权。

每次修复后重做失败项；相同错误连续两次且无新证据时停止重复操作，报告实际错误和下一步，不循环重装。

## 5. 简短交接

配置完成且默认只读验收通过时，直接报告“环境配置完成，Figma 页面读取和截图验证通过”，附实际技能路径及当前文件信息；有可信链接时才附链接。只有用户要求的验收项目未执行时才列为“未验收”，不将未请求的读写测试列为阻塞项。不要把配置存在当作连接成功。

准备好后提供一个可直接复制的登录界面练习，不再只给含 `<具体需求>`、`<ID>`、`<链接>` 的占位模板。说明“想练手时，把下面这段发给我即可”，不要自动开始新需求：

```text
$prd 带我做一个简单的 PC 网页登录界面，练习从需求澄清到 Figma 原型的过程。
产品 ID：LOGIN_DEMO。
使用刚才连接验收的 Figma Design 草稿。
界面包含账号输入框、密码输入框和登录按钮。
希望演示未填写必填项、账号或密码错误，以及登录成功后的反馈。
只做界面原型，不接真实登录接口，暂不做注册、忘记密码或第三方登录。
我没有现成的参考截图，请先说明练习需要哪些准备，再用容易回答的问题带我澄清规则；需要我确认时再进入下一阶段。
```

若已取得验收草稿的真实链接，在交接示例中将“使用刚才连接验收的 Figma Design 草稿”替换成该实际链接，方便新聊天定位；未取得则保留当前草稿表述，不要求用户先补链接才能尝试。登录规则留给用户和 prd 澄清，不把示例当作已确认需求，也不绕过 prd 的参考准备与阶段评审。
日常业务阶段和评审规则读取已安装的 prd 技能；不要在本技能复制另一套流程。项目截图放在当前 workspace 的 `Knowledge`，具体索引结构由 prd 检查，不能生成假截图或空索引冒充就绪。
